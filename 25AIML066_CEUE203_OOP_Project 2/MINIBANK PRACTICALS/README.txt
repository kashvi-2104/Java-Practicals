MINIBANK — 14 CUMULATIVE PRACTICAL CHECKPOINTS

Each Practical_XX folder contains a standalone MiniBank.java. The source is cumulative: the earlier project shell and model remain present as later layers are introduced. Practical 14 is the integrated capstone version.

Requirements: JDK 17+
Run any checkpoint: open its folder, then run `javac MiniBank.java` followed by `java MiniBank`.

Data files (accounts.dat and logs/) are created in the current working directory when you use the program. Use a separate working directory per practical if you want to keep test data isolated.
